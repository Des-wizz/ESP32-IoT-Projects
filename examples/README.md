# Examples and Experiments

Place small, focused experiments here before they become part of a larger project.

Examples may cover:

- GPIO input and output
- Button pull-up and pull-down configurations
- PWM and actuator control
- I2C and SPI communication
- Sensor reading and filtering
- Wi-Fi connectivity and data transmission

Each example should state its board, wiring, required libraries, expected behavior, and any safety considerations.
