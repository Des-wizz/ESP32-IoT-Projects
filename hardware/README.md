# Hardware

Store hardware design resources and connection information here.

Suggested contents:

- Wiring diagrams and connection tables
- Schematics and PCB source files
- Board photographs and assembly notes
- Bill of materials (BOM)
- Power requirements and voltage-level notes
- Sensor and module datasheets or links to official documentation

Keep editable source files alongside exported PDF or image previews when practical. Clearly identify hardware revisions and never assume that two visually similar modules share the same pinout.
